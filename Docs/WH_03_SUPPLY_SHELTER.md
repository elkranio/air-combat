# WH03 — Dominion field supply shelter

WH01 and WH02 forms accepted on 2026-11-27; color/identity pass deferred until the third building is accepted. WH03 completes the initial field building kit: a partly open portable supply shelter with a sloped canopy, low wind screens, exposed cargo stacks and no foundation slab. Visual only, no actual B placement, damage, collision, scoring, Picket movement or C1/C2 changes. Stock meshes are part of the shelter, not separate targets or CG01 cargo.

Open/save existing M02 with both WH01 (BD01) and WH02 visual previews installed. Run **Air Combat > Missions > M02 - Build WH03 Supply Preview**. Creates `Assets/_Project/Prefabs/Environment/WH03_SupplyShelter.prefab` and assets under `Assets/_Project/Art/Environment/Dominion/WH03_SupplyShelter`. Places the trial near WH02 with conservative spacing from WH01 and CA01, terrain sampling and collider checks. Non-collidable decoration outside the named trial roots is not checked. If no pad qualifies, the menu stops without scene changes. Select the trial root and F in Scene view; disable Carryall Firing Range and enable Start Airborne for normal flight comparison. **M02 - Remove WH03 Supply Preview** removes only the trial root. Existing generated assets are reused, not overwritten. Commit scene, generated assets and metadata after acceptance.

Geometry X16/Y7/Z22, ground-center origin, +Z open loading side. Two independent roof halves; Foundation, four frame/screen assemblies, Roof01–02 and Cargo01–02: nine assemblies, 61 closed convex source solids, 732 triangles. Cargo extends past the roof for visibility in the gameplay camera. Materials are provisional; evaluate a unified Dominion color/marking scheme next without changing the accepted silhouettes.

`Tools/Blender/build_wh03_supply_shelter.py` generates the deterministic included `WH03Geometry.json`; Blender bundled Python also exports editable `Resources/Blender/WH03_SupplyShelter.blend`. Offline checks verify closed solids, winding, nonzero triangle areas, bounds and deterministic export. Unity and Blender execution remain local gates. Next: shared paint pass, common destruction/ground damage, base layout and Picket deployment, then C1/C2 integration and mission timing.
