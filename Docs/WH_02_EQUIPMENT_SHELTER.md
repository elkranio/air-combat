# WH02 — Dominion field equipment shelter

WH01 / BD01 V2 silhouette accepted as good enough on 2026-11-27; shared livery polish deferred. WH02 is the second temporary deployment-site building. Visual-only trial; no real B placement, hitboxes, destruction, scoring, Picket movement or C1/C2 changes.

Open/save existing `Mission02_ConvoyInterdiction` with the BD01 warehouse visual trial still installed. Run **Air Combat > Missions > M02 - Build WH02 Equipment Preview**. Generates `Assets/_Project/Prefabs/Environment/WH02_EquipmentShelter.prefab` and separate mesh/material assets in `Art/Environment/Dominion/WH02_EquipmentShelter`. Places a comparison root approximately 30–48 units from WH01, on a sampled flat pad, avoiding existing colliders and the CA01 pickup pad. Non-collidable scene decoration is not covered by this check. Select the root and F in Scene view; disable Carryall Firing Range and enable Start Airborne for the normal gameplay camera. Remove only the comparison root using **M02 - Remove WH02 Equipment Preview**. Existing prefab and art are reused, never overwritten. Commit generated scene/assets/meta after local review.

Geometry: X14/Y6/Z20; ground-center origin, +Z facade. Low three-cassette roof with two raised vent assemblies, personnel door, dark side access panels, short transport skids, muted green-gray palette. Eight independent assemblies follow WH01's Foundation, four walls and Roof01–03 naming contract. 67 closed convex solids, 804 triangles; no permanent slab or interior. Colors are provisional and will be reviewed together across the field kit.

`Tools/Blender/build_wh02_equipment_shelter.py` produces the included deterministic `WH02Geometry.json`; run with Blender bundled Python to also export editable `Resources/Blender/WH02_EquipmentShelter.blend`. Offline source checks validate winding, closure, nondegenerate triangles and dimensions; Unity import and camera review remain local.
