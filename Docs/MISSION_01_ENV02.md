# ENV02 — Desert vegetation v0 (WIP)

Base `2980f9e`. Three stylized desert trees (umbrella, wind-bent, forked) and two low shrubs (saltbush and scrub), with shared matte bark and two subdued olive materials. All five source meshes are generated by `Tools/Blender/build_env02_desert_vegetation.py` (plain Python exports OBJ; Blender background additionally saves `Resources/Blender/ENV02_DesertVegetation.blend`). No textures, foliage cards, wind animation, gameplay colliders or radar contacts. Cast and receive ordinary lighting shadows. Ground and accepted ENV01B relief remain unchanged.

Open Mission01_FirstSortie in Edit Mode and run **Air Combat > Art > Apply Mission01 Desert Vegetation v0**. The installer creates reusable prefabs/materials and a separate scene root; a deterministic mix of hill-edge and independent groups, with rotated/scaled instances. Conservative X/Z bounds checks avoid existing rocks, relief, airfield, SAM renderers and other plants. Actual count depends on saved scene. Reapply replaces only ENV02; **Remove Mission01 Desert Vegetation** removes only that layer. Save scene and commit generated assets/metas after approval. Existing material/prefab tuning is preserved on reinstall.

Review in the gameplay camera; check silhouette, shadow contrast, relative scale, and density before any further foliage work. Unity/Blender execution is a local check.
