# M02 V04 — two-target flight trial

Requires M02D3 (visual Picket deployment). Open the existing saved M02 scene and run **Air Combat > Missions > M02 - Apply Two-Target Layout V04**. The installer updates the existing scene, preserves the existing convoy line reference, generates five closed rock meshes, and rebakes its tactical map. The earlier creation menu remains historical; do not regenerate M02 from M01.

C1 and C2 are two parts of ONE optional task. In this pass they are arrival markers, not destructible objectives. No deadlines or SAM firing. Preserve the previous escort setting (off for deployment observation). The final design requires both targets before expiry, never partial completion. C1's early expiry should prevent main-first and reverse-route exploits. Adjust after measuring, not before.

All route split times start on W (including takeoff). The airborne clock is retained separately. G hides the flight guides; Tab pauses the trial and opens the tactical map. R resets convoy, deployment and timing. Measure direct interception, S-C1-C2-B, and the reverse sequence and convoy-first C1 access. Existing 24-unit/s convoy speed is unchanged; the new A-B route is ~3127 units. The south corridor leaves space for a future meandering river. No river geometry is installed in this pass.

If an install fails during map baking, reopen/revert the scene and rerun the existing M02 terrain/map installer to restore the previous map bake before playing. Old rock assets are retained for now; delete after the layout is accepted.
