# MAP-02 — tactical map runtime (WIP)

Base `ecea2dff007f029aaadbb665058a17786bccd57b`. Open the baked Mission01 scene, run **Air Combat > Missions > Install Tactical Map**, review and save the scene. Tab toggles the full-screen camera-up map; Escape also closes it. Re-running the command rebinds the existing view, not a second copy. Re-bake geography normally after layout edits. No hard-coded world positions in the view.

`TacticalMapView` binds the baked `MissionMapData`, player transform, current authored SAM and objective marker transforms. It displays the runway anchor, player heading/position, planned SAM coverage, and primary/optional markers. Planned radii are read from the v3 SAM names at installation and serialized on the component; replace them with the live SAM range source when combat is wired. No mission completion/progress is fabricated. No route rails. The explicit installer is specific to the current hierarchy; the view accepts serialized references for future missions.

The map owns a temporary pause (restores prior time scale and audio pause on close/disable). The flight motor, weapon trigger, mission launch/crash and E1 debug input are gated in the map's scene; terrain warning is suppressed. Test Tab during flight, takeoff, close to rocks, with buttons held, after R, and after exiting Play Mode. Check camera-up orientation, actual positions against terrain, 6 rings and 3 recon markers, and different aspect ratios. Future live mission systems must respect pause and provide their own dynamic data; MAP-02 does not add combat or enforce boundaries.

## MAP-02B — shared camera axes

Base `ce1b3af`. The runtime map uses the same normalized horizontal camera axes and projection as RadarHud. The baked geography stays north-up; the texture and cropped coverage layer rotate together, while runway, targets, player and compass use the shared projection. Labels remain upright, and the full rotated extent fits the map panel. Non-oblique scenes without an active ArcadeCameraFollow fall back to north-up. Existing installed map bindings and baked assets are unchanged. Remove temporary diagnostic logs; keep actionable failure warnings/errors. Tab and pause semantics unchanged. Test actual heading, map/radar alignment, north indicator and all four corners, including edge-clipped SAM rings.
