# MAP-02 — tactical map runtime (WIP)

Base `ecea2dff007f029aaadbb665058a17786bccd57b`. Open the baked Mission01 scene, run **Air Combat > Missions > Install Tactical Map**, review and save the scene. Tab toggles the full-screen north-up map; Escape also closes it. Re-running the command rebinds the existing view, not a second copy. Re-bake geography normally after layout edits. No hard-coded world positions in the view.

`TacticalMapView` binds the baked `MissionMapData`, player transform, current authored SAM and objective marker transforms. It displays the runway anchor, player heading/position, planned SAM coverage, and primary/optional markers. Planned radii are read from the v3 SAM names at installation and serialized on the component; replace them with the live SAM range source when combat is wired. No mission completion/progress is fabricated. No route rails. The explicit installer is specific to the current hierarchy; the view accepts serialized references for future missions.

The map owns a temporary pause (restores prior time scale and audio pause on close/disable). The flight motor, weapon trigger, mission launch/crash and E1 debug input are gated in the map's scene; terrain warning is suppressed. Test Tab during flight, takeoff, close to rocks, with buttons held, after R, and after exiting Play Mode. Check north-up orientation, actual positions against terrain, 6 rings and 3 recon markers, and different aspect ratios. Future live mission systems must respect pause and provide their own dynamic data; MAP-02 does not add combat or enforce boundaries.
