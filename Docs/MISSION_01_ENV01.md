# ENV-01 — shallow sand relief (visual trial)

Base `ea29f3d`. Restore the original flat sand, then add a separate decorative layer of five low-poly modules: SandHump, LongDrift, BroadRise, DoubleCrest, WindRidge. The OBJ geometry is generated by `Tools/Blender/build_env01_shallow_relief.py`; ordinary Python exports the models, Blender background additionally saves `Resources/Blender/ENV01_ShallowRelief.blend`. All five OBJs are included. Blender source generation is optional for Unity import.

In Edit Mode open Mission01_FirstSortie and run **Air Combat > Art > Apply Mission01 Shallow Relief v0**. Creates five reusable prefabs alongside the OBJs and a separate scene root. Restores original sand mesh/material, keeping cast shadows off and receive shadows on. The same original sand palette UV is used by the modules; geometry/light provide the variation. The outer perimeter is slightly buried. No colliders, radar contacts, flight changes or map rebake. Modules have a nominal height of 5–12 units and asymmetric footprints. A fixed-seed placement trial uses 24 composition anchors with 2–3 candidates per group, variable yaw/scale and conservative live renderer-bound exclusion for airfield, rocks and ground objectives. Actual count depends on scene clearance. This is not final art placement and does not reserve all future patrol routes. Repeat apply replaces only this layer; remove command removes it without restoring the rejected macrotexture. Commit generated prefabs/metas and saved scene if accepted. Retain previous sand experiment assets until cleanup.

Checks: game-camera readability, ground seams, shadow consistency, no overlap with vehicles/patrols, no changes to combat or radar. Reposition instances by hand after accepting the trial. Blender/Unity application execution is local; standalone generator geometry is testable in Python.
