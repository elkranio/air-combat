# CA04 — Carryall pickup presentation

Requires the accepted CA03 preview. Existing M02 airfield-side preview, Start Airborne, R and Tab are unchanged; no menu or scene edits. Press Play. Observe the six phases from the same camera or Scene view. CA01/CG01 prefab assets, accepted meshes/materials, rotor visual, pose timing, capture logic and real C1/C2 instances are untouched.

`CarryallPickupVfx` is a disposable presentation helper owned by the scene preview. Four tapered cool-blue/white downwash plumes attach to the authored downward exhaust sockets. Thrust is smoothed by pickup phase; descent is restrained, loaded lift is strongest, departure stays strong. Plume length is limited by the sampled terrain. Four projected dust emitters are only active below 32 units of terrain clearance, strongest near the surface; particles expand, drift outward and fade in world space. Four small warm clamp puffs fire once when the successful load transition is observed, not continuously during Clamp. This is stylized visual feedback, not physical thrust or collision. No audio, new shaders, imported textures, lights, physics or damage. Uses the existing SandboxEffect shader; missing FX setup warns without blocking pickup.

Inspector on `M02 / CA01 flight preview`: Exhaust Scale (1, 0 disables), Dust Puffs Per Second (7 per nozzle before the 1.6x visibility multiplier, 0 disables), Clamp Pulse (on). Tunable live. R clears particles, returns visual thrust and phase to initial state. Tab uses existing mission pause and scaled time. Generated meshes, materials, masks and particle systems are instance-local and disposed on destruction; original art assets retain GUIDs.

Local acceptance: compile, play near the airport, check all four exhausts point down, no terrain clipping, clear rise in thrust after attachment, dust only near ground, one restrained clamp pulse, no duplicate effects on repeated R and no movement during Tab. Check Scene view and actual game camera at Y78. Reduce scale/density if noisy. No Unity Play Mode validation in the patch environment.
