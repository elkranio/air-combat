# CA01 — Dominion Carryall (accepted visual v1.0)

Accepted 2026-11-26: V8 shape + V9A+ Heavy Duty livery. Freeze geometry and paint; the temporary comparison has been removed. For runtime trials see [CA02](CA_02_FLIGHT_PREVIEW.md) through [CA05](CA_05_DESTRUCTION_PREVIEW.md). The build/apply instructions below record art authoring, not a required setup step.

Heavy angular airlift transport, inspired by classic RTS carryalls. V8 accepted geometry: removes the two tall rear bank fins that obscure the rear turbine faces in the oblique game view. V7 pod spacing (10.8), low tail plates and all other geometry retained. No new bridge. Retains the V3 cockpit and four underside capture pads. Unity dimensions X 27.3, Y 6.075, Z 23.22. The origin is the CG01 capture plane, not the ground or center of mass. CG01 local position at pickup is (0,-5,0), with identity local rotation. Four ClampSockets/Clamp_01..04 match CG01 CaptureSockets/Grab_01..04 exactly. CargoMount exposes the payload transform. Four EngineSockets/Exhaust_* transforms face downward (+Z local). 12 independently pivoted visual assemblies; 4528 base-shape triangles before V9A+ paint subdivision. No flight, damage, collision, animation, extraction or mission changes.

Open and save the existing M02 scene with CG01 installed. Run **Air Combat > Missions > M02 - Build CA01 Carryall Preview**. Builds reusable `Assets/_Project/Prefabs/Aircraft/CA01_Carryall.prefab` and assets under `Art/Aircraft/Dominion/CA01_Carryall`. Places empty and loaded visual-only comparisons beside C1 at 8 units above terrain (cargo bottom at +3). Existing mission cargo is not moved. Select the generated comparison root and press F in Scene view. Move the comparison root if desired. The two comparison stands each preserve their internal alignment. **M02 - Remove CA01 Comparison Preview** deletes just the temporary comparison root and saves the scene; prefab/assets remain. Remove the comparison before runtime integration. The initial installer refuses duplicate comparison roots. For an existing CA01 installation, use **Air Combat > Missions > M02 - Apply CA01 Carryall V9AP** in a clean saved M02 scene: it updates the existing mesh assets and prefab in place (same GUIDs, assembly names and capture interface), and retains exhaust sockets at Z +/-5.4. V9A Heavy Duty trial: graphite hull and steel-gray upper armor. V9B Industrial trial: ochre hull and golden upper armor. V9C Logistics trial: cool light-gray hull and pale armor. V9A+ (accepted): original graphite Heavy Duty palette with two mirrored yellow diagonal bands per main shoulder and a small diagonal aft dorsal marking. Existing surface triangles are subdivided along paint boundaries; no added volume, changes to silhouette, or separate decal objects. Red Dominion markings and blue glazing retained. V8 is the accepted 4528-triangle base shape. V9A+ subdivides only selected top-facing Body triangles; parent planes, surface areas, assembly pivots, dimensions and sockets are unchanged. Existing CA01 material GUIDs are retained; the menu updates their colors and rebuilds the material slots in place. The CG01 cargo is not recolored. Reimports each mesh and the prefab synchronously, then revalidates saved assembly vertex counts and pivots. V3 exposed stale Scene view geometry despite correct serialized assets; restart Unity before evaluating a new silhouette if necessary. The comparison stands and mission cargo remain in place. Review generated assets in git after the upgrade; revert on an interrupted save.
