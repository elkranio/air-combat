# CA01 — Dominion Carryall (visual trial)

Heavy angular airlift transport, inspired by classic RTS carryalls. Four rectangular engine pods, raised central beam, forward cab, four underside capture pads. Unity dimensions X 22, Y 6.2, Z 20. The origin is the CG01 capture plane, not the ground or center of mass. CG01 local position at pickup is (0,-5,0), with identity local rotation. Four ClampSockets/Clamp_01..04 match CG01 CaptureSockets/Grab_01..04 exactly. CargoMount exposes the payload transform. Four EngineSockets/Exhaust_* transforms face downward (+Z local). 12 independently pivoted visual assemblies; 1608 triangles. No flight, damage, collision, animation, extraction or mission changes.

Open and save the existing M02 scene with CG01 installed. Run **Air Combat > Missions > M02 - Build CA01 Carryall Preview**. Builds reusable `Assets/_Project/Prefabs/Aircraft/CA01_Carryall.prefab` and assets under `Art/Aircraft/Dominion/CA01_Carryall`. Places empty and loaded visual-only comparisons beside C1 at 8 units above terrain (cargo bottom at +3). Existing mission cargo is not moved. Select the generated comparison root and press F in Scene view. Move the comparison root if desired. The two comparison stands each preserve their internal alignment. **M02 - Remove CA01 Comparison Preview** deletes just the temporary comparison root and saves the scene; prefab/assets remain. Remove the comparison before runtime integration. The installer refuses duplicate comparison roots and does not overwrite generated art.

`Tools/Blender/build_ca01_carryall.py` exports the same deterministic source geometry JSON and an editable `Resources/Blender/CA01_Carryall.blend` when run with Blender's bundled Python. JSON is included; no Blender needed for Unity preview. Each source solid is editable. Current art atom only; later runtime integration owns movement and payload attachment.
