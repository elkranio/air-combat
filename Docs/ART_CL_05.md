# ART-CL-05 — Block rock trial (WIP)

Base `83e8b79`. Isolated model experiment after the camera-layout v2 review: large solid near-vertical rock blocks with localized fractures, uneven heights and two low broken slabs. No circumferential material bands or repeated terraces. Seven independently closed solids, 438 triangles total; approx. 202 x 154 ground footprint and 114 max height. Muted sandstone colors vary subtly between whole blocks rather than between horizontal layers. Existing cliff materials, scene, prefabs and lighting are unchanged by the patch.

Run **Air Combat > Missions > Place CL05 Rock Trial** in `Mission01_FirstSortie`. This builds the prefab and three new matte materials if missing, then places one editable instance at (350, 0, -650) on the existing flat mission ground. If the area is obstructed, use **Air Combat > Art > Build CL05 Test Rock** and drag `Assets/_Project/Prefabs/Environment/Cliffs/CL05_TestRock.prefab` to a clear location instead. Existing assets and trial instances are not overwritten. Save scene and generated material/prefab assets plus their .meta files only if retaining the trial. No map regeneration or runtime changes.

Each overlapping block owns a separate RadarTerrainObstacle (not the group root), preventing even-odd fill cancellation. Overlap contours may still show internal lines, as for existing modular cliffs; this trial does not implement radar union or physical collisions. Review both sides at Y78, with the normal gameplay camera and dynamic shadows. Look for a massive stone silhouette and irregular block joints rather than continuous stepped bands. Do not replace the barrier before visual approval.

Reproduce OBJ assets with `python Tools/Blender/build_cl05_test_rock.py`; use `blender --background --factory-startup --python Tools/Blender/build_cl05_test_rock.py` to additionally save the editable source in `Resources/Blender/CL05_TestRock.blend`. Blender and Unity import/compilation/Play Mode require local verification; no .blend is included. Mesh winding and closure are checked by the generator.
