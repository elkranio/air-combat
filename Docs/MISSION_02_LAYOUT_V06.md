# M02 V06 — asymmetric canyon pockets

On the installed, saved V05 scene, run **Air Combat > Missions > M02 - Apply Canyon Pockets V06**. This replaces the west massif and the two southern masses with a west massif and a continuous southern massif (four marked solids total), updates C1/C2 rings and all three optional route lines, and rebakes the tactical map. The existing terrain, airfield, northern convoy route and operation extent are preserved. Old mesh assets remain until the layout is accepted.

C1 is reached through a northeast approach, then a northwest turn into an irregular amphitheatre inside the western plateau. C2 uses a southeast approach then a southwest turn into a broader basin. Both return through their own entrances. These are two measurement points of ONE optional task, not separate rewards. No deadline, combat target, river or extra SAM is added. Existing escort and deployment settings are unchanged.

Geometric checks: 15,504 units along the three optional guide lines, 12,720 units by a visibility-graph shortest path with 35-unit rock clearance and 12-unit boundary inset. Minimum guide clearance from rock is 81.6 units; this is not a flight-time guarantee. Test S-C1-C2-B and convoy-first C1. If map baking fails, the installer rolls back scene objects and attempts to restore the old map bake; verify the scene before retrying.
