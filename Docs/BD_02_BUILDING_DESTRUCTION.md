# BD02 — expeditionary buildings / destruction trial

WH01 (BD01 V2), WH02 and WH03 silhouettes accepted for mission testing. Paint and art polish deferred. No edits to models, materials, real depot B, Picket routes or C1/C2.

Open existing M02 and run **Air Combat > Missions > M02 - Enable BD02 Building Destruction** once. The menu validates the three existing prefab assets and upgrades them in place, preserving their GUIDs, visual assemblies and preview locations. Review and commit the three changed prefab assets after local validation. Disable Carryall Firing Range and enable Start Airborne on Mission02RouteTrial, then Play. Use RMB NURS on the existing airport-side building previews. R restores the buildings along with the sortie; Tab pauses collapse. Select a building instance to see HP in the Inspector. All three default to 3 HP, provisional and adjustable. AC01 does not damage ground-domain targets. One NURS blast applies one damage per target via the existing GroundBlastDamage policy.

`DepotBuildingTarget` owns HP, one coarse non-trigger BoxCollider (full authored bounds, including WH03's open bays), an idempotent Destroyed event, and the visual collapse. At zero HP the collider turns off, existing roof and wall assemblies fall/tilt outward, WH03's cargo shifts, the foundation remains, and instance-only paint darkens. Existing GroundCrashFeedback provides a short fire/dust/smoke/fragment burst without extra audio or camera shake. Wreck persists until R; no separate wreck mesh, Rigidbody, chain explosion, sustained smoke or geometry fragmentation. Ground-contact approximation assumes a flat pad and identity Visual hierarchy. Future vehicle layout must use authored building footprints, not rely on disabled wreck colliders.

Acceptance: shoot each type with real NURS, check HP and one-time destruction, no damage from AC01, R during collapse and after collapse, no accumulated parts/effects, no shared material changes.
