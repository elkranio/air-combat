# Air Combat

Unity 6.6 / URP arcade air-combat prototype. The accepted gameplay is in committed scenes and prefabs, not in one-shot scene generators.

## Playtest scenes

- `Assets/_Project/Scenes/WeaponLab.unity` — authoritative air-combat regression (player, fighter AI, BURST/GAUSS/MISSILE).
- `Assets/_Project/Scenes/GroundAttackLab.unity` — ground-combat regression (four Military Depots, bombs, NURS, shared lighting), one AA turret and R1 radar.
- `Assets/_Project/Scenes/Sandbox.unity` — legacy flight/missile comparison; **the only Build Settings scene**.
- `Assets/_Project/Scenes/FrontierStrata.unity` — V17 environment art baseline. The other Frontier/bake scenes remain art references, not gameplay scenes.

**Controls (WeaponLab + GroundAttackLab):** A/D steer, constant 70 cruise, W afterburner to 140 (2.5s full tank), Q/E Break Turn, R reset, H diagnostics **off by default**. S/Space unused. WeaponLab: 1 BURST, 2 GAUSS, 3 MISSILE, B enemy evasion. GroundAttackLab also has **4 BOMBS** (four gravity bombs, .25s spacing, 3s cooldown, nadir/height-only marker) and **5 NURS** (committed 2.5s climb, six physical rockets, 2.5s return, Q/E emergency abort). No NURS impact predictor; G4c adds aircraft-safe camera lead instead. **R1** adds a small, translucent heading-up radar (bottom-left, above fuel strip) to GroundAttackLab, with 460-unit detection and AA danger ring. Sandbox retains its original W/S + Space controls.

## Source ownership

```text
Assets/_Project/
  Scenes/                           # Committed playable scenes
  Prefabs/Aircraft/                 # PlayerJet, EnemyJet
  Prefabs/Camera/                   # CombatCameraRig
  Prefabs/Chassis/                  # Kestrel geometry and sockets
  Prefabs/Environment/              # CombatLightingRig (one light/shadow authority)
  Prefabs/Enemies/                  # AA1Autocannon (generated by AA1 installer)
  Scripts/Aircraft,Flight,Enemy/    # Reusable aircraft, radar sensor, maneuver and AA turret behavior
  Scripts/Weapons,Combat,Targeting/ # Weapons, ground-domain damage, targeting
  Scripts/Camera,Environment/       # Camera behaviors, shared URP lighting
  Scripts/Scenes/                   # Lab-only runtime scene composition
  Scripts/Visual,UI/                # Effects, markers, radar rendering and presentation
```

Keep `PlayerJet`, `CombatCameraRig`, and `CombatLightingRig` reusable; scene-specific links belong in session binders. Real shadows come from the shared URP lighting prefab and mesh renderers; `AircraftGroundShadow` is **legacy Sandbox-only**. Never regenerate accepted scenes via retired `ConfigureWeaponLab*` or one-time authoring commands.
